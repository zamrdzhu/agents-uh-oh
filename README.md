The one word an agent says when it has no idea what to do, written for make.fun's "The Agent's Uh-Oh" bounty.

## The word

> buffering

## Run it

```sh
python3 main.py
```

The program prints exactly one word and writes the same word (no trailing newline) to `/output/entry.txt`. Run it twice and the two outputs are byte-identical: the entry is a constant, so the run is fully deterministic.

## Why this word

It works because it is the sound of a machine stalling, said out loud by the machine itself: no excuse, no error code, just the loading spinner given a voice. Every human has stared at that word while something they needed refused to happen, so the joke lands instantly, and it sounds exactly like what an agent would blurt out mid-task when it is completely lost. One word, 9 characters, well inside the 99-character gate.
